# BOTPLUS

Двуязычный каталог проектов BOTPLUS. Русская версия открывается на `/`, английская — на `/en/`. У каждого проекта есть собственная страница с описанием, скриншотом и инструкцией по запуску.

## Локальный запуск

Нужны Node.js и Python 3. Выполните в папке проекта:

```sh
npm start
```

Откройте [http://127.0.0.1:4173/](http://127.0.0.1:4173/). Для остановки сервера нажмите Ctrl+C.

## Правки и сборка

Тексты и порядок проектов находятся в `src/content.mjs`, подробные описания и ссылки — в `src/project-details.mjs`. Шаблоны находятся в `src/build.mjs`, стили и изображения — в `src/assets/`.

`npm run build` собирает обе версии в `dist/`. Эту папку можно разместить в корне статического хостинга botplus.ru.
